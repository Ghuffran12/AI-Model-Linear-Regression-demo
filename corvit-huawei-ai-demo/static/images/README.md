# static/images/

This folder is intentionally empty.

Corvit Huawei AI Demo's visuals (the plot diagram, feature icons, charts) are
drawn with inline SVG and Chart.js rather than raster images, so the site has
no bitmap assets to ship or optimize. Drop any screenshots, a favicon source,
or marketing images here if you add some later — `base.html` already points
its favicon at an inline data-URI SVG, so swap that `<link rel="icon">` tag
to point here if you add a real one.
