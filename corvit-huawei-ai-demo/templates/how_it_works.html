From input to estimate

How it works

Five steps turn a plot size into a price estimate — every one of them runs for real on every request, in this order, with nothing skipped or faked in between.

  1. 1

    The customer enters plot information

    Either a plot area directly, or a length and breadth, in square yards, square feet, square meters or acres — typed in, or pre-filled from one of the quick-select sizes on the Home and Predictor pages.

  2. 2

    The application validates and converts the measurements

    The backend rejects empty, negative, non-numeric or non-finite values, checks that an entered area agrees with length × breadth when both are given, and converts everything into a single canonical unit — square yards — using the documented conversion constants (1 sq yd = 9 sq ft = 0.836127 sq m; 1 acre = 4,840 sq yd).

  3. 3

    The trained Linear Regression model processes the input features

    The plot area and the one-hot encoded locality are assembled into the exact feature row the model was trained on, and passed to model.predict(...) — the real, already-fitted scikit-learn LinearRegression object loaded from models/linear_regression_model.joblib, not a stand-in formula.

  4. 4

    The application calculates and displays the estimated price

    The model's raw output becomes the headline prediction, and the backend derives price per square yard, per square foot and per acre from it, formats everything in {{ currency_code }}, and returns it as structured JSON that the Predictor page renders — including the plot size, dimensions and locality that produced it.

  5. 5

    The customer reviews the result and its limitations

    Every result carries a disclaimer: this is a Linear Regression estimate trained on synthetic demonstration data, not a verified market valuation. Plot sizes outside {{ min_sqyd|commas }}–{{ max_sqyd|commas }} square yards are declined outright rather than guessed at — see Model Insights for exactly how accurate the model is on data it has never seen.
