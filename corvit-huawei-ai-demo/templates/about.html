About this project

About Huawei AI Demo

An educational artificial-intelligence and machine-learning demonstration built to show a complete, working Linear Regression pipeline end to end — from raw data to a live web prediction.

What this is

Huawei AI Demo is an educational demonstration of applied machine learning, developed to showcase how a classic statistical model — Linear Regression — can be trained, evaluated and shipped inside a real, usable web application. It estimates property plot prices from plot size and locality.

Every prediction shown on this site is produced live by a genuine scikit-learn LinearRegression model, trained on a clearly-labelled synthetic dataset generated for this demonstration (see ml/generate_dataset.py for the documented pricing assumptions used to create it). No real property-market data was collected or used.

What this is not

This project is not an official product, service or certification of Huawei or of Corvit, and it does not imply an endorsement or partnership between them. It is not a real estate valuation tool, and its output must not be used to make actual buying, selling or investment decisions.
